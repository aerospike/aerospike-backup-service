## dto.AzureStorageClass
AzureStorageClass represents the configuration for Azure Blob Storage access tiers.

| Field      | Description                                                                                                        |
|------------|--------------------------------------------------------------------------------------------------------------------|
| `data`     | DataClass specifies the storage tier for object data.<br>See: [dto.AzureDataClass](dto.azuredataclass.md)          |
| `metadata` | MetadataClass specifies the storage tier for metadata.<br>See: [dto.AzureMetadataClass](dto.azuremetadataclass.md) |
