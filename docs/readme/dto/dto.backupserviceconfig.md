## dto.BackupServiceConfig
BackupServiceConfig represents the backup service configuration properties.

| Field    | Description                                                                                                         |
|----------|---------------------------------------------------------------------------------------------------------------------|
| `backup` | Backup contains service-level backup settings.<br>See: [dto.ServiceBackupConfig](dto.servicebackupconfig.md)        |
| `http`   | HTTPServer is the backup service HTTP server configuration.<br>See: [dto.HTTPServerConfig](dto.httpserverconfig.md) |
| `logger` | Logger is the backup service logger configuration.<br>See: [dto.LoggerConfig](dto.loggerconfig.md)                  |
