## dto.S3StorageClass
S3StorageClass represents the configuration for S3 Storage Class.

| Field      | Description                                                                                                   |
|------------|---------------------------------------------------------------------------------------------------------------|
| `data`     | DataClass specifies the storage class for object data.<br>See: [dto.S3DataClass](dto.s3dataclass.md)          |
| `metadata` | MetadataClass specifies the storage class for metadata.<br>See: [dto.S3MetadataClass](dto.s3metadataclass.md) |
