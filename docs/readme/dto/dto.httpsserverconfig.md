## dto.HTTPSServerConfig
HTTPSServerConfig represents the service's HTTPS server configuration.

| Field                    | Description                                                                                                                                                                                                                                          | Default Value | Possible Values                         |
|--------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|-----------------------------------------|
| `address`                | The address to listen on.                                                                                                                                                                                                                            | `0.0.0.0`     |                                         |
| `cert-file`              | Path to the HTTPS server certificate in PEM format.                                                                                                                                                                                                  |               |                                         |
| `cipher-suites`          | Allowed TLS cipher suite names. An empty list uses Go's secure defaults.                                                                                                                                                                             |               |                                         |
| `client-auth`            | Client certificate authentication mode.<br>See: [dto.TLSClientAuth](dto.tlsclientauth.md)                                                                                                                                                            | `none`        | `none`, `request`, `require-and-verify` |
| `client-ca-file`         | Path to trusted client CA certificates in PEM format.                                                                                                                                                                                                |               |                                         |
| `context-path`           | ContextPath customizes the path for API endpoints.                                                                                                                                                                                                   | `/`           |                                         |
| `disabled`               | Disabled controls whether the HTTPS listener is disabled.                                                                                                                                                                                            | `false`       |                                         |
| `idle-timeout`           | IdleTimeout is the maximum time in milliseconds to wait for the next keep-alive request.                                                                                                                                                             | `120000`      |                                         |
| `key-file`               | Path to the HTTPS server private key in PEM format.                                                                                                                                                                                                  |               |                                         |
| 🔒 `key-file-password`    | Passphrase for an encrypted HTTPS server private key.<br>This is sensitive information. Can be a path in secret agent or an actual value.<br>Literal values are redacted as "[secret]" in API responses; secret agent references are returned as-is. |               |                                         |
| `min-version`            | Minimum accepted TLS protocol version.<br>See: [dto.TLSMinVersion](dto.tlsminversion.md)                                                                                                                                                             | `1.2`         | `1.2`, `1.3`                            |
| `port`                   | The port to listen on.                                                                                                                                                                                                                               | `8443`        |                                         |
| `rate`                   | HTTP rate limiter configuration.<br>See: [dto.RateLimiterConfig](dto.ratelimiterconfig.md)                                                                                                                                                           |               |                                         |
| `read-timeout`           | ReadTimeout is the maximum duration in milliseconds for reading an entire request.                                                                                                                                                                   | `30000`       |                                         |
| `secret-agent`           | Secret Agent configuration (optional).<br>Mutually exclusive with 'secret-agent-name'.<br>See: [dto.SecretAgent](dto.secretagent.md)                                                                                                                 |               |                                         |
| `secret-agent-name`      | Secret Agent configuration (optional). Link to one of preconfigured agents.<br>Mutually exclusive with 'secret-agent'.                                                                                                                               |               |                                         |
| `timeout`                | Timeout for reading HTTP request headers in milliseconds.                                                                                                                                                                                            | `5000`        |                                         |
| `write-timeout`          | WriteTimeout is the maximum duration in milliseconds before timing out response writes.                                                                                                                                                              | `60000`       |                                         |
🔒 = Redacted in API responses
