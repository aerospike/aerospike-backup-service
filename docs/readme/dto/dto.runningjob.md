## dto.RunningJob
RunningJob tracks progress of currently running job.

| Field                 | Description                                                                                                                                                                                                                                               |
|-----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `done-records`        | The number of records that have been successfully backed up so far.<br>For a server-side backup, the count can exceed the number of distinct records.                                                                                                     |
| `duration`            | Duration represents the elapsed time taken by the job in seconds.                                                                                                                                                                                         |
| `estimated-end-time`  | The estimated time when the backup operation will be completed.<br>It is calculated based on the current percentage done and duration.<br>A nil value indicates that the estimation is not available yet.<br>This value is not guaranteed to be accurate. |
| `finish-time`         | The time when the operation finished.<br>A nil value indicates that the operation is still running.                                                                                                                                                       |
| `metrics`             | Metrics provides real-time information about data flow performance.<br>A server-side backup shows the rates the server last reported.<br>See: [dto.Metrics](dto.metrics.md)                                                                               |
| `percentage-done`     | The progress of the backup operation as a percentage.<br>This value is not guaranteed to be accurate.                                                                                                                                                     |
| 🖥️ `server-jobs`      | The server jobs of a running server-side backup: one per namespace whose job has reported<br>its status, each as the server last reported it.<br>Array of: [dto.ServerBackupJob](dto.serverbackupjob.md)                                                  |
| `start-time`          | The time when the operation started.                                                                                                                                                                                                                      |
| 🔍 `total-records`     | The total number of records to be processed.<br>Zero for a server-side backup, whose progress the server reports only as a percentage.                                                                                                                    |

🔍 = Only backup-mode `scan` accepts this field
🖥️ = Only backup-mode `server` accepts this field
