## dto.RunningJob
RunningJob tracks progress of currently running job.

| Field                | Description                                                                                                                                                                                                                                               |
|----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `done-records`       | The number of records that have been successfully done.                                                                                                                                                                                                   |
| `estimated-end-time` | The estimated time when the backup operation will be completed.<br>It is calculated based on the current percentage done and duration.<br>A nil value indicates that the estimation is not available yet.<br>This value is not guaranteed to be accurate. |
| `finish-time`        | The time when the operation finished.<br>A nil value indicates that the operation is still running.                                                                                                                                                       |
| `metrics`            | Metrics provides real-time information about data flow performance.<br>See: [dto.Metrics](dto.metrics.md)                                                                                                                                                 |
| `percentage-done`    | The progress of the backup operation as a percentage.<br>This value is not guaranteed to be accurate.                                                                                                                                                     |
| `start-time`         | The time when the operation started.                                                                                                                                                                                                                      |
| `total-records`      | The total number of records to be processed.                                                                                                                                                                                                              |
