## dto.BackupCommonConfig
BackupCommonConfig represents service-level backup settings.

| Field               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Possible Values   |
|---------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------|
| `schedule-timezone` | Timezone for evaluating backup cron expressions (optional).<br>Accepted values: UTC (default), Local, or any IANA timezone name resolvable<br>by Go's time.LoadLocation (for example, America/New_York or Japan).<br>Keywords UTC and Local are case-insensitive; IANA names are case-sensitive.<br>Prefer canonical Area/Location names: legacy aliases such as EST resolve as<br>fixed UTC-5 with no DST, which is rarely what "Eastern Time" is meant to be.<br>Changing this service-level default requires a restart. |                   |
| `timestamp-format`  | Encoding for backup date in human-readable format in backup file paths (optional).<br>Allowed values:<br>* ISO (e.g. 2006-01-02T15-04-05)<br>* EU (e.g. 02-Jan-2006-15-04-05)<br>* US (e.g. Jan-02-2006-15-04-05)                                                                                                                                                                                                                                                                                                          | `ISO`, `US`, `EU` |
