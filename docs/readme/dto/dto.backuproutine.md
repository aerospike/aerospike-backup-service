## dto.BackupRoutine
BackupRoutine represents a scheduled backup operation routine.

| Field                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Default Value |
|-----------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|
| 📍 `interval-cron`     | The interval for full backup as a cron expression string.<br>Cron expression format: https://github.com/reugn/go-quartz?tab=readme-ov-file#cron-expression-format                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |               |
| 📍 `namespaces`        | The list of namespaces to back up.<br>If empty, the entire cluster is backed up.<br>The order of namespaces does not determine the backup execution or completion order.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |               |
| 📍 `source-cluster`    | The name of the corresponding source cluster.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |               |
| 📍 `storage`           | The name of the corresponding storage provider configuration.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |               |
| `backup-policy`       | The name of the corresponding backup policy, one of defined in `config.backup-policies` (optional).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |               |
| `bin-list`            | The list of backup bin names (optional, an empty list implies backing up all bins) extensions:"x-nullable".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |               |
| `disabled`            | Whether this routine is disabled and should not run. Default: false.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | `false`       |
| `incr-interval-cron`  | The interval for incremental backup as a cron expression string (optional).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |               |
| `node-list`           | NodeList specifies which Aerospike nodes to include in the backup.<br>Only the listed nodes will be backed up.<br>Each node can be specified as one of the following:<br>- "<IP address>:<port>"<br>- "<hostname>:<port>"<br>- "<node ID>"<br>To obtain node identifiers, run: `asinfo -v "service:"`.<br>If using IP addresses or hostnames, ensure they match the values returned by the `asinfo` command.<br>Mutually exclusive with partition-list and rack-list in this routine,<br>and also mutually exclusive with the cluster's prefer-racks setting.<br>Parallelism is determined by the number of listed nodes unless `BackupPolicy.Parallel` is set to a lower value. |               |
| `partition-list`      | PartitionList defines the list of partitions to include in the backup.<br>The format supports individual partitions or ranges.<br>- A range is specified as "<start>-<count>" (e.g., "100-50" backs up 50 partitions starting from 100).<br>- A single partition is specified as a number (e.g., "0").<br>Multiple entries can be comma-separated: e.g., "0,100,200,300,400,500".<br>By default, all partitions (0 to 4095) are backed up.<br>Mutually exclusive with node-list and rack-list in this routine,<br>and also mutually exclusive with the cluster's prefer-racks setting.                                                                                           |               |
| `rack-list`           | RackList specifies the Aerospike Server rack IDs from which to read records<br>during backup.<br>If provided, only nodes belonging to these specified racks will be scanned.<br>If the list is empty or omitted, no rack filtering is applied.<br>Mutually exclusive with partition-list and node-list in this routine,<br>and also mutually exclusive with the cluster's prefer-racks setting.                                                                                                                                                                                                                                                                                  |               |
| `secret-agent`        | The name of a Secret Agent to read secrets from (optional).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |               |
| `set-list`            | The list of backup set names (optional, an empty list implies backing up all sets).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |               |

📍 = Required field
