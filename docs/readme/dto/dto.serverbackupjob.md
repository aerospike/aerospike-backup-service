## dto.ServerBackupJob
ServerBackupJob is a server-side backup job of one namespace, as the server last reported it.

| Field                 | Description                                                                                                                                                                                                                                                                                                                                                             |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `abort-origin`        | What aborted the job, passed on as the server names it: operator for a request to abort,<br>server for a failure on a node, cluster for a cluster event.                                                                                                                                                                                                                |
| `bytes-backed-up`     | The number of bytes backed up.                                                                                                                                                                                                                                                                                                                                          |
| `error-reason`        | Why the job failed or was aborted, as the server reports it.                                                                                                                                                                                                                                                                                                            |
| `finish-time`         | The time the job finished.                                                                                                                                                                                                                                                                                                                                              |
| `job-id`              | The server's job id.                                                                                                                                                                                                                                                                                                                                                    |
| `namespace`           | The namespace the job backed up.                                                                                                                                                                                                                                                                                                                                        |
| `records-backed-up`   | The number of records backed up.                                                                                                                                                                                                                                                                                                                                        |
| `records-read-failed` | The number of records the server could not read. When it is above zero the backup lacks<br>those records, even if the job's state is COMPLETE.                                                                                                                                                                                                                          |
| `start-time`          | The time the job started.                                                                                                                                                                                                                                                                                                                                               |
| `state`               | The job state across the cluster's nodes, as last reported. While the job runs it is the<br>state of the node furthest behind, such as BASE_SCAN_ACTIVE, ABORTING while a failure or an<br>abort settles on every node, or UNKNOWN for a state the service does not know. It ends as<br>COMPLETE, FAILED or ABORTED. A job that stopped reporting keeps its last state. |
