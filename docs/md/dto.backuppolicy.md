## dto.BackupPolicy
BackupPolicy represents a scheduled backup policy.

| Field                        | Description                                                                                                                                                                                                                                                                                                                                                                       | Default Value |
|------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|
| `bandwidth`                  | Throttles backup write speed to a maximum of the specified bandwidth in MiB/s.<br>Default is no limit.                                                                                                                                                                                                                                                                            | `0`           |
| `compression`                | Compression details (algorithm and mode). Default is no compression.<br>Enabling compression reduces storage and network usage, but increases CPU usage during the backup.<br>Depending on the system configuration, compression may improve or degrade overall performance.<br>See: [dto.CompressionPolicy](dto.compressionpolicy.md)                                            |               |
| `concurrent-incremental`     | Allows incremental backups to run concurrently.<br>When false (default), incremental backups are skipped if another backup for same routine is in progress.                                                                                                                                                                                                                       | `false`       |
| `encryption`                 | Encryption details (algorithm and key). Default is no encryption.<br>See: [dto.EncryptionPolicy](dto.encryptionpolicy.md)                                                                                                                                                                                                                                                         |               |
| `file-limit`                 | File size limit (in MB) for the backup directory. If an .asb backup file crosses this size threshold,<br>a new backup file will be created.                                                                                                                                                                                                                                       | `250`         |
| `no-indexes`                 | Do not back up any secondary index definitions.                                                                                                                                                                                                                                                                                                                                   | `false`       |
| `no-records`                 | Do not back up any record data (metadata or bin data).                                                                                                                                                                                                                                                                                                                            | `false`       |
| `no-udfs`                    | Do not back up any UDF modules.                                                                                                                                                                                                                                                                                                                                                   | `false`       |
| `parallel`                   | Maximum number of scan calls to run in parallel. Each scan call processes a subset of the total<br>data partitions. The optimal value depends on hardware and network configuration.                                                                                                                                                                                              | `8`           |
| `records-per-second`         | Limits the number of records returned per second (RPS). Default is no limit.                                                                                                                                                                                                                                                                                                      | `0`           |
| `retention`                  | Specifies how long to retain full and incremental backups.<br>Cleanup runs asynchronously after each successful full backup, never deleting backups preemptively.<br>Ensure storage capacity for at least one extra full backup beyond the retention configuration.<br>See: [dto.RetentionPolicy](dto.retentionpolicy.md)                                                         |               |
| `retry-policy`               | RetryPolicy defines the configuration for database scan retry attempts in case of failures.<br>If nil, the default policy is used (5 retries with a one-minute delay between attempts).<br>See: [dto.RetryPolicy](dto.retrypolicy.md)                                                                                                                                             |               |
| `sealed`                     | Sealed determines whether backup should include keys updated during the backup process.<br>When true, the backup contains only records that last modified before backup started.<br>When false (default), records updated during backup might be included in the backup, but it's not guaranteed.<br>This parameter does not affect XDR backups (which always includes all keys). | `false`       |
| `socket-timeout`             | Socket timeout in milliseconds. Default is 10 minutes. If this value is 0, it is set to total-timeout.<br>If both are 0, there is no socket idle time limit.                                                                                                                                                                                                                      | `60000`       |
| `total-timeout`              | Total socket timeout in milliseconds. Default is 0, that is, no timeout.                                                                                                                                                                                                                                                                                                          | `0`           |
| `with-cluster-configuration` | Back up Aerospike cluster configuration.                                                                                                                                                                                                                                                                                                                                          | `false`       |
