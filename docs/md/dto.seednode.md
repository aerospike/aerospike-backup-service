## dto.SeedNode
SeedNode represents details of a node in the Aerospike cluster.

| Field                                       | Description                                                    |
|---------------------------------------------|----------------------------------------------------------------|
| `host-name`<span style="color:red">*</span> | The host name of the node.                                     |
| `port`<span style="color:red">*</span>      | The port of the node.                                          |
| `tls-name`                                  | TLS certificate name used for secure connections (if enabled). |
