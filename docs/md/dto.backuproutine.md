## dto.BackupRoutine

| Field                                            | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Default Value |
|--------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|
| `interval-cron`<span style="color:red">*</span>  | The interval for full backup as a cron expression string.<br>Cron expression format: https://github.com/reugn/go-quartz?tab=readme-ov-file#cron-expression-format                                                                                                                                                                                                                                                                                                                                                                                                                        |               |
| `source-cluster`<span style="color:red">*</span> | The name of the corresponding source cluster.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |               |
| `storage`<span style="color:red">*</span>        | The name of the corresponding storage provider configuration.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |               |
| `backup-policy`                                  | The name of the corresponding backup policy, one of defined in `config.backup-policies` (optional).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |               |
| `bin-list`                                       | The list of backup bin names (optional, an empty list implies backing up all bins) extensions:"x-nullable".                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |               |
| `disabled`                                       | Whether this routine is disabled and should not run. Default: false.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `false`       |
| `incr-interval-cron`                             | The interval for incremental backup as a cron expression string (optional).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |               |
| `namespaces`                                     | The list of the namespaces to back up (optional, empty list implies backup of the whole cluster).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |               |
| `node-list`                                      | NodeList specifies which Aerospike nodes to include in the backup.<br>Only the listed nodes will be backed up.<br>Each node can be specified as one of the following:<br>- "<IP address>:<port>"<br>- "<hostname>:<port>"<br>- "<node ID>"<br>To obtain node identifiers, run: `asinfo -v "service:"`.<br>If using IP addresses or hostnames, ensure they match the values returned by the `asinfo` command.<br>This field is mutually exclusive with partition-list.<br>Parallelism is determined by the number of listed nodes unless `BackupPolicy.Parallel` is set to a lower value. |               |
| `partition-list`                                 | PartitionList defines the list of partitions to include in the backup.<br>The format supports individual partitions or ranges.<br>- A range is specified as "<start>,<count>" (e.g., "100,50" backs up 50 partitions starting from 100).<br>- A single partition is specified as a number (e.g., "0").<br>Multiple entries can be comma-separated: e.g., "0,100,200,300,400,500".<br>By default, all partitions (0 to 4095) are backed up.<br>This field is mutually exclusive with node-list.                                                                                           | `0-4096`      |
| `prefer-racks`                                   | The list of Aerospike Server rack IDs to prioritize when reading records during backup.<br>This is optional and can be used to optimize for rack-aware deployments.                                                                                                                                                                                                                                                                                                                                                                                                                      |               |
| `secret-agent`                                   | The name of a Secret Agent to read secrets from (optional).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |               |
| `set-list`                                       | The list of backup set names (optional, an empty list implies backing up all sets).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |               |
