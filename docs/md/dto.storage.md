## dto.Storage

| Field           | Description                                                                                             |
|-----------------|---------------------------------------------------------------------------------------------------------|
| `azure-storage` | AzureStorage configuration, set if using Azure storage.<br>See: [dto.AzureStorage](dto.azurestorage.md) |
| `gcp-storage`   | GcpStorage configuration, set if using GCP storage.<br>See: [dto.GcpStorage](dto.gcpstorage.md)         |
| `local-storage` | LocalStorage configuration, set if using local storage.<br>See: [dto.LocalStorage](dto.localstorage.md) |
| `s3-storage`    | S3Storage configuration, set if using S3 storage.<br>See: [dto.S3Storage](dto.s3storage.md)             |
