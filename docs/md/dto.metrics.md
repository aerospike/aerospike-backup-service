## dto.Metrics
Metrics represents the current job speed.

| Field                  | Description                                                                                                                                                                                                                                                                                                                                                                                                                    |
|------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `kilobytes-per-second` | KilobytesPerSecond indicates the amount of data processed by storage per second, in kilobytes.                                                                                                                                                                                                                                                                                                                                 |
| `pipeline`             | Pipeline represents the number of records that have been read from the source<br>but not yet written to the destination. This metric helps identify bottlenecks:<br>- If Pipeline is zero or fluctuates near zero, it means the destination is consuming data<br>  faster than the source can read.<br>- If Pipeline grows large, it indicates that the source is producing data faster<br>  than the destination can consume. |
| `records-per-second`   | RecordsPerSecond indicates the number of records processed by Aerospike per second.                                                                                                                                                                                                                                                                                                                                            |
